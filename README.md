# القرآن الكريم — نور | EASY CODE

تطبيق قرآن كامل يعمل **بدون إنترنت** (PWA):

- نص المصحف بالخط العثماني (رواية حفص عن عاصم) — مصدر: tanzil.net
- ١٢ ترجمة: روسية (كوليف، بوروخوفا، عثمانوف)، إنجليزية، فرنسية، ألمانية، إسبانية، تركية، إندونيسية، أردية، صينية، فارسية
- ٩ لغات للواجهة (عربي، روسي، إنجليزي، فرنسي، ألماني، إسباني، تركي، إندونيسي، أردو)
- فهرس ١١٤ سورة + ٣٠ جزءاً، بحث فوري في النص والترجمة، محفوظات، متابعة القراءة
- ٥ لوحات ألوان، خط أميري أو خط الجهاز، أحجام خطوط قابلة للضبط
- استماع للآيات (مشاري العفاسي) عبر الإنترنت

## التشغيل محلياً
```
python3 -m http.server 8080
```
